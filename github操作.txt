日常开发标准流程（背这一套）
git pull                        # 1. 先同步最新
git checkout -b feature/xxx     # 2. 新建分支干活
# ... 写代码 ...
git add .                       # 3. 暂存
git commit -m "描述做了什么"    # 4. 提交
git push -u origin feature/xxx  # 5. 推送到 GitHub
修改远程地址
git remote set-url origin https://github.com/你的用户名/CUDA-Programming.git
